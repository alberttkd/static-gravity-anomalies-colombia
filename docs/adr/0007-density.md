# ADR 0007: Reference density 2670 kg m⁻³, 2300 as scenario

- Status: accepted (2026-10-22)
- Decision record: DEC-07 in MASTER_GUIDE §4.10

## Context

2.67 g/cm³ is the national/international convention; the legacy spreadsheets used 2300 (F-02). Data-driven estimates are not constrainable here (H5).

## Decision

Report CBA at 2670; produce the 2300 scenario; Nettleton/Parasnis as diagnostics with CIs.

## Change if

The application mandates 2300 (Q6): swap reference and scenario.
