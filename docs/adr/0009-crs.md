# ADR 0009: EPSG:4326 storage, EPSG:9377 analysis

- Status: accepted (2026-10-22)
- Decision record: DEC-09 in MASTER_GUIDE §4.10

## Context

Distances and variograms must be metric (F-07, F-13).

## Decision

Store lon/lat; analyse in MAGNA-SIRGAS 2018 / Origen-Nacional; display in EPSG:3857.

## Change if

Legacy coordinates may refer to an older datum (e.g. Bogotá 1975): transform them first.
