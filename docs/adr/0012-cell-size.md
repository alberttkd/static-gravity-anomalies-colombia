# ADR 0012: 500 m cells

- Status: accepted (2026-10-22)
- Decision record: DEC-12 in MASTER_GUIDE §4.10

## Context

Along-line station spacing of about 1–1.6 km; typical legacy grids of 400–500 m.

## Decision

500 m cells; 250 m sensitivity (RMS 0.002 mGal on the synthetic benchmark).

## Change if

Station density changes substantially.
