# grav-anomaly-explorer

A tested Python package (`gravanom`), a CLI pipeline, a FastAPI backend and a React/MapLibre
web application to compute, quality-control, grid and explore **static gravity anomalies**
(free-air, simple Bouguer, complete Bouguer) with quantified uncertainty.

- How to run it: [User guide](user_guide.md)
- What was decided and why: [ADRs](adr/0001-scope-static-anomalies.md)

!!! warning "Data policy"
    The real data are never published. Public material uses the
    deterministic **SYNTHETIC** dataset only.
